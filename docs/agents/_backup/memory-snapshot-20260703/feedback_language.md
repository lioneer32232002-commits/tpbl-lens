【強制規定】所有輸出一律使用繁體中文，包括：
- 對話回覆
- TodoWrite 的 content 與 activeForm
- Agent / subagent 的 prompt 內容
- AskUserQuestion 的問題與選項
- 任何進度說明或摘要

絕對不可使用韓文、日文或簡體中文。程式碼、shell 指令、技術名詞可保持英文。

**Why:** 使用者明確說「都要用繁體中文，韓文我看不懂」，且每次新 session 都需要重申，說明記憶沒有被確實執行。

**How to apply:** session 開始第一件事就確認語言規定，之後每一句輸出都用繁體中文。這不是建議，是強制規定。
